## 課堂怎麼跑（第 2 節，老師手機；11/15 整節改過）

> 11/14～15 第 2 節改方向：前測、後測、三感官接龍都拿掉，改成「學生自己看 13 張圖 → 老師帶速讀、中間穿插題目 → 關燈講幾米的故事 → 開燈看最後兩張」。題組 `L2` 現在是 19 項：引起動機 1 題、看圖 1 項、圖片 13 張、速讀題 4 題。**四題速讀題是 AI 先放的草稿，等老師定。**

每一題的按鈕順序固定是：**出題 → 關閉作答 → 顯示結果 → 下一題**（老婆 11/06 定）。輪到哪一步，那顆按鈕就亮黃色。圖片那幾項沒有作答，只有「▶ 下一張」。

1. **前一天**：確認圖片已上傳（老師頁「圖片」區按「檢查圖片齊不齊」，要看到「13 張都在」），然後按「現在關閉」。
2. **課前**：投影機那台電腦開 `screen.html`（會放大 QR code）；手機開 `teacher.html?set=L2`（筆電也行，畫面會自動變兩欄），打密碼，到「工具」按**新回合**（投影與計數歸零；還開著舊座號的平板會回到「選座號」畫面，不用重掃）。第 1 節（`?set=L1`）不一樣：新回合後投影先放課文封面、沒有 QR，老師先帶課文，要開始問卷再按手機上的「▶ 開始互動式問卷（投影：QR CODE）」。
3. **學生掃碼、按座號**：投影幕上座號會一個個亮起來，手機上看到「n 人已加入」。平板上會顯示自己的座號＋「已加入 ✓　請把平板蓋上，眼睛看老師」。
4. **引起動機（打字題）**：按「▶ 出第 1 題：引起動機」。句子即時出現在投影幕（不帶座號）；手機上點一句，投影幕最上面會放大那句。人齊了按「關閉作答」。
5. **學生自己看圖**：按「▶ 下一題：自己看圖」。平板變成整面看圖（左右滑或按箭頭，兩指撥開可放大）；投影幕顯示「在平板上安靜看圖」。按「⏱ 投影倒數」的 3／4／5 分，投影幕出現大大的倒數。這一步會自動把圖片開放。
6. **帶速讀**：按「▶ 下一張：圖 01」。投影幕整面放那張圖，平板變成「眼睛看投影幕」。一張一張按下去；中間排了題目的地方，按鈕會變成「▶ 下一題：速讀 ①」，照平常的順序走（關閉作答 → 顯示結果 → 下一張）。
7. **講幾米的故事**：看完圖 11 按「收題（投影：平板蓋上）」，關燈。這時圖片會自動關閉。
8. **開燈看最後兩張**：按「▶ 下一題：圖 12」（圖片會自動再開放），再按「▶ 下一張：圖 13」。
9. **下課後**：「工具」→「匯出這回合的答案（CSV）」；「圖片」區按**「刪除圖片」**。

出錯了怎麼辦：按錯 → 「◀ 上一題／上一項」或題目清單裡「出這題」跳回去，答案都還在。收題後想接著出 → 「▶ 下一題」會接在最後出過的那一項後面。想暫停作答但留在那題 → 「關閉作答」，再按一次就「開放作答」。倒數按錯 → 「停止倒數」。投影或平板顯示「圖片還沒開放」→ 老師頁在題目清單把那一項再按一次「出這題」。

## 繪本圖片：放在哪、誰看得到、怎麼管（11/15 加）

**圖不放在這個資料夾。** 這個倉庫是公開的，任何人都能看到裡面的檔案，而且刪掉的檔在舊版紀錄裡還拿得到。所以書頁的掃描圖放在資料庫（跟學生答案同一個地方），下課後整包刪掉就真的沒了。

**門禁**：資料庫規則平常不讓任何人讀圖。老師頁出「自己看圖」或「圖片」那幾項時，會把開放的時間點寫進資料庫；規則只在那之後 90 分鐘內放行，過了自動關，按「收題」、「新回合」或「現在關閉」也會關。開放、上傳、刪除都要老師密碼，不知道密碼的人做不到。

**老師頁「圖片」區的四顆按鈕**：

| 按鈕 | 做什麼 |
|:--|:--|
| 上傳圖片… | 一次選全部的圖。**檔名就是編號**（`01.jpg`～`13.jpg`）。會自動縮到長邊 1600、轉成 JPEG（一張約 200～400 KB）再存進資料庫。同一個編號再傳一次＝換掉舊的 |
| 檢查圖片齊不齊 | 先開放，再一張一張抓抓看，列出缺哪幾張。上課前一天按一次 |
| 現在關閉 | 馬上關閉（檢查完、試跑完按） |
| 刪除圖片 | 把這個題組的圖全部刪掉。**下課後按** |

**第一次用之前**：要把本資料夾的 `database.rules.json` 整份貼到 Firebase 主控台（Realtime Database →「規則」分頁 → 全選換掉 → 發布）。新規則只是多了三段（`key`、`pics`、`gallery`），原本的五段一個字沒動。沒貼之前，出圖片那幾項會跳一次「圖片開不起來」，題目照常能出。

**換圖、換張數**：圖的編號寫在 `questions.js` 的 `PAGES`，順序排在題組 `L2` 裡。

**本機試流程**：網址加 `?local=1`（三個頁面都加，例如 `teacher.html?local=1&set=L2&r=dev`）就不會碰正式資料庫；圖從 `gallery-local/L2/01.jpg`… 讀，這個資料夾列在 `.gitignore`，不會進版本紀錄。

## 上線後改東西

改好 → `git add 改的檔` → `git commit` → `git push`，約一分鐘後網址就是新版，網址與 QR code 不變。兩條規矩：上課或試用當下不存新版；存新版後平板還看到舊畫面就關掉重開。

存新版後如果老師頁或投影頁一直停在「載入中…」：是瀏覽器還留著舊的程式檔（網頁換新了、它引用的檔還是舊的）。電腦按 Ctrl+F5 強制重新整理，iPad 把分頁關掉重開；放著不管最多 10 分鐘也會自己好。所以**上課前至少 15 分鐘就不要再存新版**。

## 改題目／改班級

只改 `questions.js`：
- `SETS` 裡加一個題組或改選項，不用碰其他檔。選擇題 4 個以內的選項用 A～D 四色、一列一個；超過 4 個（例如 0～9＋摸不出來）會自動改成格子排、投影長條變矮，選項字兩字以內就直接當標籤；`type: 'multi'` 是複選（學生點一個存一個、再點取消，存檔的 `v` 是選項文字用「、」接起來、`is` 是編號；長條圖與手機分布的百分比分母是作答人數）；開放題 `prefix` 會自動接在學生打的字前面；`compareWith` 讓投影頁把這題和指定的題並排；`type: 'slide'` 是不作答的投影頁（目前只有點字對照表，畫在 `braille.js`；`highlight` 是按「顯示答案」要加黃框的數字、`student` 是平板上那行字）；`type: 'gallery'` 是學生在平板上自己看一組圖（`images`＝圖的編號）；`type: 'pic'` 是投影幕整面放一張圖（`img`＝編號；題組裡用 `pic('03')` 這個小工具寫）。圖怎麼上傳見上面「繪本圖片」一節。
- 題組加 `cover: { image: '檔名.jpg', title: '…' }`，新回合一開始投影就整面放那張圖（圖放在本資料夾；第 1 節的 `cover-L1.jpg` 是課本第 48 頁上半的照片拉正提亮、抹掉「改寫自」那行），老師頁多一顆「開始互動式問卷」切到掃碼畫面；拿掉 `cover` 就一開始直接是掃碼畫面。
- 換班級：改 `DEFAULT_ROOM`（教室代碼，換了舊答案就看不到）與 `DEFAULT_N`（座號到幾號）。
